# Brand assets

The original owner-approved source is
`YALKEN_CANONICAL_BRAND_DESIGN_PACK_2026-07-19`. The current Dock icon is the
owner-requested enlarged variant, not a byte-identical original-pack export.

- `app-icon.svg` is the editable source. Only the mark transform differs from
  the original `Yalken_AppIcon_Light_Master.svg`:
  `translate(295.905882353 120) scale(1.317647058824)`.
  The mark is 784px high, centered in the unchanged 912px tile, with 64px
  inner clearance above and below. Canonical path, palette, tile and shadow
  are unchanged; the original pack stays untouched.
- `logo.png` and `build/icon.png` are the same 1024px render of this enlarged
  source (SHA-256
  `49a07604f7400f410093a69f03f7ca637b1db3edded60c448a8bfc58598f5ae7`).
- `build/icon.icns` is regenerated from that PNG by the native script below.
- The titlebar uses the exact canonical `328:595` Y path inline in
  `index.html`, with neutral theme ink and no CSS mask or bitmap background.
  The existing system title is separate; no wordmark font is installed.

`bash scripts/make-mac-icon.sh` regenerates the build PNG/ICNS from the prepared
1024px source using macOS `sips` and `iconutil`. The build PNG preserves source
PNG bytes; the ICNS 1024px slot preserves decoded RGBA pixels. Only the standard
smaller iconset slots are downsampled; no contrast or black padding is added.
ICNS container bytes may differ when regenerated by the native tools.
