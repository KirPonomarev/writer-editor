# Brand assets

The owner-approved source is `YALKEN_CANONICAL_BRAND_DESIGN_PACK_2026-07-19`.

- `logo.png` and `build/icon.png` are byte-exact copies of its prepared
  `Yalken_AppIcon_Light_1024.png` (SHA-256
  `ef424c96caa2beef9cb388d78149c478259089dfd689e77771363269f6f8edc2`).
- `build/icon.icns` is its prepared `Yalken_AppIcon.icns` (SHA-256
  `620b06c16550a3e59b0302a5afdaa00d645bff80e1705970bf1ba8a9c40d276b`).
- The titlebar uses the exact canonical `328:595` Y path inline in
  `index.html`, with neutral theme ink and no CSS mask or bitmap background.
  The existing system title is separate; no wordmark font is installed.

`bash scripts/make-mac-icon.sh` regenerates the build PNG/ICNS from the prepared
1024px source using macOS `sips` and `iconutil`. The build PNG and the ICNS
1024px slot preserve source PNG bytes, alpha and colors. Only the standard
smaller iconset slots are downsampled; no contrast or black padding is added.
ICNS container bytes may differ when regenerated by the native tools.
