## Contract

V2 wire retains schemaVersion, baselineTextSha256 and edits. Every edit carries
id, historyId, direction, fromParagraphIndex/fromUtf16,
toParagraphIndex/toUtf16, removedParagraphs and insertedParagraphs. Ordered
nonempty string arrays distinguish hardBreak LF within a paragraph from actual
paragraph boundaries. Enter maps [''] to ['','']; join maps ['',''] to [''].
Use actual PM coordinates and slices, not string diff or quote search.
The new renderer ledger emits V2 consistently, including same-leaf edits;
Core still reads V1. Save ACK matches exact pending prefixes and incarnation.

Same-leaf list/table edits retain current support. Any edit crossing paragraph
boundaries or changing their count requires ordinary root paragraphs, even if
the final count is unchanged. Core verifies ownership and exact before/final
replay; unsupported drafts remain available and canonical writes refuse.

StateV5 adds versioned history with independent historical ordinals and kind
transitions. Keep old groups and truthful per-leaf/span hashes; never fabricate
old full-scene hashes. Structural deletion retains original quote/anchor and
uses a separate Core-proved collapsed live locator bound to the current block.
Matching history/session and source/target bindings, not matching text, permit
Undo restoration. Further same-group typing moves the proven locator without
reviving a deleted discussion. Manual/remote tombstones never revive.

Legacy V1-V4 readers/writers and monotonic transaction versions remain covered.
Readers for generic import, ordinary/review export and authenticated return
accept V5 through existing validation. Tree history that cannot be mapped into
an exact partition refuses before publication; preserve legacy leftmerge and
supported identity-only rename. Never clear history to make a command pass.
